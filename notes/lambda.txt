Create a role "photowords-lambda-role" having the following policies:
1. AWSLambdaBasicExecutionRole: Provides write permissions to CloudWatch Logs.
2. AWSLambdaVPCAccessExecutionRole: Provides minimum permissions for a Lambda function to execute 
   while accessing a resource within a VPC - create, describe, delete 
   network interfaces and write permissions to CloudWatch Logs.
3. parameter-read-access: to allow getting parameter
4. photowords-lambda-policy: This policy grants full read and write access to four 
   specific DynamoDB tables (photowords_users, photowords_images, 
   photowords_image_groups, and photowords_game_attempts)
5. photowords-s3-access-policy: Grants permissions to read, write, list, and delete objects in the photowords S3 bucket.
